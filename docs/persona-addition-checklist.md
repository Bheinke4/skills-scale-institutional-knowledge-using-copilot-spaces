# Persona Addition Checklist

Use this checklist when adding a new persona to docs/octoacme-roles-and-personas.md.

- [ ] Persona name and one-line summary added
- [ ] Responsibilities list (3–6 bullets) included
- [ ] Interaction section: describe how this persona interacts with PM, PdM, Developers, QA, and Ops
- [ ] Examples of decisions or handoffs the persona owns (e.g., release signoff, capacity decisions)
- [ ] Add references to related process docs (planning, release, risk) and link to issue/PR that introduced the persona
- [ ] Confirm acceptance criteria: content aligns with existing process docs
- [ ] Stakeholder review: identify reviewers (e.g., PdM, PM, Engineering Manager, Security) and capture sign-off in PR description
